3. PROMPT FOR ER DIAGRAM

Create a Classical Chen ER Diagram for an Online Course Enrollment System.

Entities:

- STUDENT: student_id (PK), student_name, mobile, email, address
- COURSE: course_id (PK), course_name, duration, course_fee
- INSTRUCTOR: instructor_id (PK), instructor_name, email, specialization
- ENROLLMENT: enrollment_id (PK), student_id (FK), course_id (FK), enrollment_date, enrollment_status

Relationships:

- STUDENT — HAS — ENROLLMENT
- ENROLLMENT — SELECTS — COURSE
- COURSE — TAUGHT_BY — INSTRUCTOR

Use:

- Rectangle → Entity
- Oval → Attribute
- Diamond → Relationship
- Underline → Primary Key
- Clearly mark Foreign Keys
- Show proper cardinality (1:M)
- Keep the diagram clean and readable.
